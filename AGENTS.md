# AGENTS.md – dev-templates

## Document IDs

- Project key: `DVT` (three uppercase letters, unique across Tim's projects)
- Issues: `DVT-ISS-NNNN`
- ADRs: `DVT-ADR-NNNN`
- File names remain `NNNN-short-title.md`; the key appears in document titles, index tables, and references only.
- The key convention is defined in `docs/issues/README.md` and `docs/adr/README.md`; consuming projects define their own key in their `AGENTS.md`.

## Project Language

The project language is defined here in `AGENTS.md`, individually per artifact type. Consuming projects set their own values in their `AGENTS.md`.

- **Documentation** (issues, ADRs, general adoc/md/text documents): English – the lingua franca of this repo
- **Program code** (identifiers, naming): English (no program code exists in this documentation-only repo)
- **Code comments**: English (no program code exists in this documentation-only repo)
